## Описание
Проект состоит из 2 частей: клиента и сервера
Клиент при старте запрашивает обновления у сервера. Сервер, делая некие проверки(см. ниже), шлёт ответ, есть обновления или нет.
Если нет обновлений, клиент запускает игру и завершает работу.
Если обновления есть, то клиент тоже делает некоторые проверки:
<ul>
    <li>Не запускался ли файл раньше(информацию в случае запуска он сохраняет в регистрах Windows)</li>
    <li>Нет ли в данный момент активных процессов с именем, которое есть в специальном списке, присланном сервером при первом запросе</li>
</ul>
Если ничего из этого не найдено, скачивает обновление(один исполняемый файл) с сервера и запускает его.
Во всех случаях клиент повторно делает запрос на сервер, но уже с отчётом: скачал ли он файл или нет, если нет, то по какой причине(файл запускался до этого, найдены запущенные процессы из списка, не найден такой файл на сервере), если да, то за какое время скачался файл.
Серверная программа состоит из 2 частей.
Одна "общается" с клиентом. При первом запросе(на наличие обновлений) она смотрит, не находится ли ip клиента в списке запрещённых, не принадлежит ли этот ip стране из списка запрещённых. Если обновлений нет или если клиент не прошёл по фильтрам, отвечаем соответсвенно, что обновлений нет. Если всё успешно, то отвечаем, что обновления есть, и прикрепляем нужные данные(имя скачиваемого файла, список запрещенных процессов и др.).
При первом запросе создается лог в БД, где пишется информация о клиенте и результат запроса. При втором(отправка отчёта) сервер обновляет запись, добавляя информацию о результате скачивания.
Вторая часть сервера - админка. Простая страница, где можно просмотреть логи за определённую дату. Кроме того есть различные фильтры и сортировки для более удобного просмотра

## Стек технологий
Лаунчер написан на C++. Использует WindowsAPI
Серверная часть написана на PHP. Используется БД MySQL
