## Описание
Утилита берёт текст пользователя и "прячет" его внутри файла любого изображения(любого, но главное, чтобы размера изображения хватило для хранения сообщения - программа проверяет это условие). Точно так же она может и декодировать зашифрованное до этого сообщение. После кодировки изображение визуально почти не меняется(заметить можно только если вручную сравнивать каждый пиксель).  
Для кодирования сообщения на вход программе подаётся текст, который надо зашифровать и путь к изображению, в которое надо положить зашифрованное сообщение. Для декодирования изображения надо подать на вход путь к изображению, где закодировано сообщение.  
Пока что поддерживается только формат BMP
## Внутренности
Проект написан на чистом Си  
### Алгоритм кодирования/декодирования
В каждый байт изображения(используются байты, хранящие цвет) записывается(через побитовое ИЛИ) один бит исходного сообщения(младший бит изображения начинает хранить бит сообщения). Таким образом, все биты сообщения распределются по байтам изображения.
