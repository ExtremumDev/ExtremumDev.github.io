Выполнен по заказу для компании N(связанной с добычей полезных ископаемых)  

## Описание
Сайт работает, как плафторма-реестр, хранит в себе данные о связанных предприятиях, деталей-компонентах, используемых на определённых предприятиях, умеет формировать отчёты о проверке этих деталей, формировать отчёты в виде заготовок для pdf и doc документонов.

## Стек технологий
Язык программирования python, фреймворк django

## Изображения
Сверху вниз соответственно: реестр компонентов, по которым ведётся учёт; список отчётов по каждой детали; пример документа, который автоматически формируется по каждому отчёту
