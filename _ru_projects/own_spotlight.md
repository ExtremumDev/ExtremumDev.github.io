## О проекте
<p>Моя собственная утилита, аналог spotlight(mac os), для быстрого поиска информации и много другого</p>

## Стек технологий

GUI планируется сделать с помощью фреймворка Qt
## Текущий статус / этап
Разрабатываю ядро программы - запуск обработчиков в тредах, уведолмение тредом о найденном результате

## Как работает программа
Как только пользователь ввёл текст, программа запускает обработчики введённого текста. Обработчик - объект, который должен по исходному тексту что-то найти, вычислить или что-то еще и подготовить это для выдачи результата пользователю. Пока что делаю 2 вида обработчиков: один ищет файлы, второй, если исходный текст состоит только из арифмитических символов, пытается обработать введённый текст, как арифмитическое выражение, и выдать его результат.  
Каждый обработчик запускается в отдельном треде. Если он что-то нашёл/высчитал, то через специальный объект-контейнер результатов добавляет в список результатов свой результат. Перед этим он должен захватить мьютекс контейнера(так как список результатов сам по себе является критической секцией)
